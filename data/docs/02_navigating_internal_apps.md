# Navigating Internal Applications

Scientists rely on several specialized internal applications during a
normal working day. This guide explains how to find them and which one to
use for common tasks.

## The Application Catalog

The Application Catalog is the canonical index of every internal tool. You
can reach it from the corporate homepage or directly through your browser
bookmark. Each entry includes a short description, the responsible owner,
and a link to launch the tool. When you cannot remember the exact name of
an application, search the catalog by keyword.

## Choosing the Right Tool

The two most common confusions are between similarly named applications
and between deprecated and current applications. As a rule:

- Sample tracking is performed in the Sample Stock app, not in the older
  Lab Inventory app, which has been retired.
- Instrument bookings are handled in the Instrument Scheduler.
- Cleaning, decontamination, and safety records are stored in the
  Lab Operations Hub.
- Incident reporting goes through ServiceNow, not through internal email.

If you are unsure which tool to use, the assistant can guide you to the
correct one — describe the task and the assistant will suggest the right
catalog entry.

## Bookmarks and Pinning

Pin the applications you use most often to your browser bookmark bar.
There is no single landing page that contains every tool; the catalog
intentionally keeps each application separate so that each owner can
update theirs independently.

## When a Tool Looks Wrong

If an application looks different from yesterday, it has probably been
updated. Release notes are linked from the application footer. If
behaviour seems broken — not just changed — open a ServiceNow incident
and describe what you expected versus what you observed.
